# Proyecto Sonrisas VR Visual Pack

[English](README.en.md) | [Español](README.md)

Planned images for the **Proyecto Sonrisas VR** project.

This directory is prepared to include the project's visual assets in original and web-optimized versions.

- `proyectosonrisas-cover.png`
- `proyectosonrisas-banner.png`
- `proyectosonrisas-thumbnail-01-vr-scene.png`
- `proyectosonrisas-thumbnail-02-object-interaction.png`
- `proyectosonrisas-thumbnail-03-tomato-targets.png`
- `proyectosonrisas-thumbnail-04-comfort-design.png`

- `proyectosonrisas-cover.webp`
- `proyectosonrisas-banner.webp`
- `proyectosonrisas-thumbnail-01-vr-scene.webp`

## Recommended usage

- `proyectosonrisas-logo.webp` for project identity.
- `proyectosonrisas-cover.webp` for Open Graph, cover and social sharing.
- `proyectosonrisas-banner.webp` for the portfolio website.
- Thumbnails for cards, documentation, README files or technical previews.
